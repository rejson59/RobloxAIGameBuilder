    Zmiany robi ten sam model AI, którego użyłeś do generowania (wymaga klucza API).

    Krok 1 — pobierz wtyczkę z wbudowaną grą

    Wtyczka nie łączy się z internetem, żeby zbudować grę: cały kod Luau i mapa są w środku pliku. Połączenie z tym serwerem jest potrzebne tylko do funkcji „Zmień grę (AI)” w panelu wtyczki — tam też wklejasz klucz API (trzymany wyłącznie w pamięci sesji Studia, nigdy nie jest zapisywany w pliku wtyczki).

    Wtyczka zapamięta dostawcę i model z panelu po lewej: —

    Krok 2 — wgraj do Roblox Studio

    1. Roblox Studio → Plugins → Plugins Folder (otworzy folder).
    2. Skopiuj plik *.plugin.luau do tego folderu.
    3. Zrestartuj Studio. Na pasku pojawi się Roblox AI Game Builder:
      • Buduj grę — wstawia mapę i skrypty w otwarte miejsce (z Ctrl+Z),
      • AI Builder — panel: zmiany przez AI, skan zaślepek, darmowe assety, ikona.
    4. Żeby działały zmiany przez AI: w Studio Game Settings → Security → Allow HTTP Requests.

    Adres serwera dla wtyczki

    Wtyczka działa w Twoim Studiu na tej samej maszynie, dlatego używa 127.0.0.1 (nie adresu podglądu w chmurze).
